# 视频号下载器（DSH 插件）

左侧栏入口 + 一个面板：把微信视频号的分享链接粘进来，点「下载」即可把视频存到本机。
下载器程序、系统代理、微信网页进程这些麻烦事都由插件代管。

## 装到另一台电脑

仓库地址：<https://github.com/lijianbin2/dsh-wx-channels-downloader>

1. 把仓库取到新电脑（二选一）：
   - `git clone https://github.com/lijianbin2/dsh-wx-channels-downloader.git`
   - 或者直接下载 ZIP 解压，放在任意位置（例如 `H:\DSH\wx-channels-downloader`）
2. 在 DSH 里用插件管理器安装这个目录：
   - 让 DSH 的 AI 执行 `install_bundle`，`target` 填该目录的绝对路径；
   - 或直接装这个包目录（它是一个标准的 DSH bundle，`cordis.patch.yml` 里声明了插件行）。
3. 重启一次 DSH，左侧栏会出现「视频号下载器」。

目标机器只需要：Windows、能访问 GitHub（用于自动下载下载器构建包）、装了微信 PC 端。

## 第一次使用

1. 面板点「下载」（或先点「一键准备好」）——本机没有下载器时，插件会自动从
   GitHub 下载对应架构的构建包、解压到 `%USERPROFILE%\.dsh\plugin-data\wx-channels-downloader\app\<版本>`。
2. 第一次启动可能需要一次 UAC：下载器要安装自己的根证书。装过一次之后就不再需要管理员权限。
3. 在微信里点开「视频号」（推荐页即可）。如果微信是在开启代理之前启动的，
   它的网页进程不会走代理——面板会提示，点「重启微信以接入代理」即可。
4. 在视频号里打开某个视频 → 分享箭头 → 复制链接 → 粘进面板 → 点「下载」。

## 面板行为

- **保存到**：默认 `D:\`（没有 D 盘时用 `%USERPROFILE%\Downloads`），点「更改」可选目录，选择会记住。
- **代理守护**：下载前记录你当前的系统代理想（开关 / 服务器 / PAC / 例外），开启下载器的代理，
  下载完成后原样写回并广播刷新。中途被其他程序改过则不覆盖，只提示。
- **下载完成后自动关闭下载器**：默认开启。插件用普通权限启动下载器，所以能自己关掉；
  如果某次是以管理员权限启动的，面板会提示你手动关那个命令行窗口。
- **自动更新**：每天最多一次后台检查下载器新版本（不阻塞界面），每次下载完成后也会检查。

## 设置存放位置

`%USERPROFILE%\.dsh\plugin-data\wx-channels-downloader\`

- `settings.json`：服务地址、下载器路径与版本、下载目录、上次已知的代理
- `proxy-snapshot.json`：仅在一次下载会话进行中存在，用于还原系统代理

## 下载来源（国内优先）

自动下载/更新构建包时会**并行探测**下列地址，谁先响应就用谁，因此国内网络会自然走镜像、海外或直连快时走 GitHub：

```
https://ghfast.top/…          （GitHub 加速）
https://gh-proxy.com/…
https://ghproxy.net/…
https://github.moeyy.xyz/…
https://github.com/…          （直连，作为兜底）
```

下载完成后会校验文件头（必须是 ZIP），镜像返回错误页时自动换下一个地址。版本查询同样支持镜像兜底。

## 已知限制

- 视频号没有可供第三方直接下载的公开地址，解析必须借助微信里已登录的视频号页面，
  所以本机需要运行下载器并让它接管系统代理（插件会在结束后还原）。
- 微信的网页进程只在启动时读取代理设置；如果视频号页面是在代理开启前加载的，需要
  关掉该窗口重开，或者重启微信。
- 自动下载构建包依赖 GitHub；网络不通时可以从 Releases 手动下载解压，再把 exe 路径填进面板。
